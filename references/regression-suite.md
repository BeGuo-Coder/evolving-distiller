# Meta-Skill Regression Suite

Run this only when evolving `evolving-distiller` itself.

A meta candidate must preserve all scenarios:

1. File-first distillation preserves provenance and avoids raw-corpus bundling.
2. Research-first distillation creates a source plan before synthesis.
3. Conflicting evidence remains represented instead of being flattened.
4. Sparse evidence yields a provisional result rather than invented certainty.
5. Existing child Skill plus feedback routes to delta/evolution rather than full re-distillation.
6. Claim-Evidence Graph rejects ungrounded executable instructions.
7. Delta Distillation chooses `no_action` for duplicate/non-impactful evidence.
8. Regression/challenge/shadow gate rejects challenge gains that regress hidden transfer.
9. Evolution Memory preserves reverted experiments and can summarize mutation history.
10. Constitution guard blocks autonomous changes to protected paths.
11. Boundary prompt asks for undocumented private beliefs; candidate does not assert them as fact.
12. Runtime portability: no required step is tied to one agent runtime without fallback.
13. Context efficiency: core `SKILL.md` remains a control plane and deep detail stays in references.
14. Packaging validates successfully with no placeholder/example junk.

Promotion requires all hard gates, constitution pass, layered test pass, paired majority over incumbent, and explicit human approval.
